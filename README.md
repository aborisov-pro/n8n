## Технический стек

| Компонент | Решение |
|-----------|---------|
| Платформа | n8n (self-hosted) |
| БД / кэш | Supabase (PostgreSQL) · Redis |
| LLM | DeepSeek · Qwen · YandexGPT · OpenAI · LangChain Agents |
| Триггеры | Telegram Bot · Webhook · Schedule · HTTP Request · RSS/Atom |
| Доставка | Telegram Bot API · MAX Messenger · Email |
| Интеграции | Google Calendar · Gmail · Google Sheets · YouTube Data API |
| Внешние API | HH.ru · OpenMeteo · OpenWeatherMap |
| Логика | Code (JS) · IF/Switch/Merge · Custom Nodes · Error Workflow |
| Бэкап | pg_dump через SSH → Supabase Storage |

> DeepSeek и Qwen подключены через прямой API — в 17–20 раз дешевле Yandex Cloud при сопоставимом качестве.

## Архитектурные принципы

- **Централизованное логирование** — все воркфлоу пишут логи через Писца в Supabase
- **Redis-дедупликация** — новости не повторяются между выпусками
- **Двухфазные воркфлоу** — сборщик работает в фоне, респондер отвечает мгновенно из кэша
- **Фольклорные имена** — каждый бот получает славянское имя и характер: Зорька, Ясень, Садко, Подьячий...
