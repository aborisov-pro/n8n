# 🐱 Персы — мониторинг Ирана: военные сводки и углеводороды

> Telegram-бот с двухфазной архитектурой: фоновый сборщик + респондер по запросу.  
> Живой бот: [@Chto_tam_u_persov_bot](https://t.me/Chto_tam_u_persov_bot)

---

## Что делает бот

Следит за происходящим в Иране: военные действия, санкции, добыча и экспорт нефти и газа.

По запросу пользователя в Telegram бот:
1. Читает свежие статьи из Redis-кэша (собранные фоном каждые 15 минут)
2. Фильтрует по теме через предфильтр по ключевым словам
3. Анализирует через LLM (Mercury-2, Яндекс Облако)
4. Подтягивает текущие котировки нефти
5. Добавляет историю сюжетов из Redis
6. Отправляет структурированный дайджест в Telegram

## Архитектура

```
┌─────────────────────────────────────────────────────┐
│  COLLECTOR (каждые 15 мин)                          │
│  Schedule Trigger → RSS-ленты → Нормализация        │
│  → Дедупликация → Redis-кэш статей                  │
└─────────────────────────────────────────────────────┘
                        ↓ кэш
┌─────────────────────────────────────────────────────┐
│  RESPONDER (по запросу пользователя)                │
│  Telegram Trigger → Redis: читать кэш               │
│  → Предфильтр по теме → LLM-анализ (Mercury-2)     │
│  → Котировки нефти → История сюжетов               │
│  → Финальный отчёт в Telegram                       │
└─────────────────────────────────────────────────────┘
                        ↓ логирование
┌─────────────────────────────────────────────────────┐
│  ПИСЕЦ (централизованный логгер, отдельный воркфлоу)│
│  ← Execute Workflow Trigger: штатный лог            │
│  ← Error Trigger: перехват ошибок + Telegram-алерт  │
│  → Supabase: таблица workflow_logs                  │
└─────────────────────────────────────────────────────┘
```

## Технический стек

| Компонент | Решение |
|-----------|---------|
| Платформа | n8n (self-hosted) |
| LLM | Mercury-2 (Яндекс Облако) через OpenAI-совместимый API |
| Кэш / дедупликация | Redis (10 операций на запрос) |
| Источники | RSS-ленты (международные и RU) |
| Доставка | Telegram Bot API |
| Логирование | Supabase `workflow_logs` через воркфлоу **Писец** |

## Узлы (45 нод)

| Группа | Узлы |
|--------|------|
| Триггеры | Schedule (15 мин), Telegram Trigger, Manual |
| Redis | Кэш статей, история сюжетов, котировки, счётчик промо, lastSeen |
| Обработка | Предфильтр по ключевым словам, нормализация, дедупликация, постфильтр |
| LLM | Общий разбор через Mercury-2 |
| Вывод | Разбивка на части (лимит TG 4096), финальный отчёт, промо |
| Инфра | Вызов логгера Писец |

## Особенности реализации

- **Двухфазность**: сборщик работает независимо от респондера — бот отвечает мгновенно из кэша
- **Промо-счётчик**: каждый N-й запрос показывает промо-сообщение (Redis-счётчик)
- **История сюжетов**: бот помнит ранее освещённые темы и добавляет их в контекст LLM
- **Котировки нефти**: Brent/WTI подтягиваются в реальном времени и включаются в промпт
- **Разбивка сообщений**: длинный ответ автоматически делится на части
- **Централизованное логирование**: все события передаются в воркфлоу Писец → Supabase. Ошибки перехватываются автоматически с алертом в Telegram

## Зависимость: Писец

Этот воркфлоу использует **[Писец](../pisec/)** — централизованный логгер.

| Вход Писца | Что происходит |
|------------|----------------|
| `Execute Workflow Trigger` | Штатный лог → Supabase |
| `Error Trigger` | Перехват ошибок → Supabase + Telegram-алерт |
| `Schedule` 03:00 | Ежедневный pg_dump → Supabase Storage |

> ⚠️ Импортируй и активируй Писца первым.

3. Настроить credentials: Redis, Telegram, OpenAI-совместимый (Mercury-2), Supabase
4. Активировать воркфлоу
