# 🎉 Поздравлятор — бот-поздравитель в мессенджере Макс

> Вебхук-бот: пользователь описывает кого и с чем поздравить — бот генерирует короткое персональное поздравление с юмором и отправляет обратно.

---

## Что делает бот

Пользователь пишет боту в мессенджере Макс — кого поздравляем, с чем, любые детали (профессия, увлечения, возраст, характер). Бот извлекает контекст, генерирует поздравление на 3–4 предложения и немедленно отвечает в чат.

Никаких штампов: «счастья, здоровья, успехов» и «пусть сбываются мечты» — под запретом. Только живой текст с лёгкой иронией, подходящими эмодзи и деталями из сообщения.

## Архитектура

```
┌─────────────────────────────────────────────────────┐
│  ВХОДЯЩИЙ ЗАПРОС                                    │
│  Мессенджер Макс → Вебхук (POST)                    │
│  → ИИ-агент (LangChain + Mercury-2)                 │
│  → HTTP POST обратно в Макс                         │
└─────────────────────────────────────────────────────┘
                        ↓ логирование
┌─────────────────────────────────────────────────────┐
│  ПИСЕЦ (централизованный логгер, отдельный воркфлоу)│
│  ← Set LOG: формирует объект лога                   │
│  ← Execute Workflow Trigger: штатный лог            │
│  ← Error Trigger: перехват ошибок + Телеграм-алерт  │
│  → Supabase: таблица workflow_logs                  │
└─────────────────────────────────────────────────────┘
```

## Технический стек

| Компонент | Решение |
|-----------|---------|
| Платформа | n8n (self-hosted) |
| LLM | Mercury-2 (Inception) — прямой API от разработчика модели |
| Подключение к LLM | Нода OpenAI Chat Model с кастомным base URL (OpenAI-совместимый интерфейс) |
| Агент | LangChain Agent (n8n-nodes-langchain) |
| Мессенджер | Макс (platform-api.max.ru) |
| Логирование | Supabase `workflow_logs` через воркфлоу **Писец** |

---

## Узлы (6 нод)

| Узел | Роль |
|------|------|
| Вебхук | Приём POST от мессенджера Макс |
| ИИ-агент | LangChain-агент с системным промптом |
| OpenAI Chat Model | Mercury-2 через Inception API (подключён как OpenAI-совместимая нода) |
| Отправить в Макс | HTTP POST с текстом поздравления обратно в чат |
| Set LOG | Формирует объект лога: имя воркфлоу, execution ID, статус, фрагмент ответа |
| LOG через Писец | Асинхронный вызов централизованного логгера |

---

## Особенности реализации

- **Промпт-логика**: имя именинника берётся из сообщения; если не указано — используется имя отправителя. Праздник определяется из текста; если не указан — подбирается ближайший по текущей дате
- **Запрет штампов**: «счастья, здоровья», «пусть сбываются мечты» и подобные клише явно запрещены в системном промпте
- **Формат ответа**: маркдаун, отправляется через `format: markdown` в теле запроса к API Макса
- **Устойчивость**: HTTP-нода работает в режиме `continueRegularOutput` — ошибка API Макса не останавливает воркфлоу
- **Асинхронный лог**: Писец вызывается с `waitForSubWorkflow: false` — ответ пользователю не задерживается логированием

## Зависимость: Писец

Этот воркфлоу использует **[Писец](../pisec/)** — централизованный логгер.

| Вход Писца | Что происходит |
|------------|----------------|
| `Execute Workflow Trigger` | Штатный лог → Supabase |
| `Error Trigger` | Перехват ошибок → Supabase + Телеграм-алерт |

> ⚠️ Импортируй и активируй Писца первым.

## Порядок установки

1. Импортировать и активировать **Писца** (`pisec/pisec.json`)
2. Импортировать этот воркфлоу: **Settings → Import workflow → `Pozdravlyator_Generate_Greeting.json`**
3. Настроить кредлы: Mercury-2 (Inception API через OpenAI-ноду с кастомным base URL), Макс (HTTP Header Auth)
4. В Макс Developer Portal зарегистрировать вебхук: `https://<твой-домен>/webhook/max-pozdravlyator`
5. Активировать воркфлоу
