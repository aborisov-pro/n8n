# 🧠 Прошка — идеи и календарь

> Telegram-ассистент: из одного сообщения понимает, что перед ним идея или событие, и либо сохраняет идею в Supabase, либо добавляет запись в Google Calendar.

---

## Что делает

Прошка принимает входящие сообщения из Telegram и сначала проверяет, что сообщение пришло от разрешённого `chat_id`. Это защищает воркфлоу от случайных или чужих запросов.

После проверки воркфлоу без LLM-классификатора определяет тип сообщения. Если в тексте есть явные признаки даты и это не помечено как «идея», запрос идёт в календарную ветку. Всё остальное попадает в ветку идей.

В календарной ветке AI-агент на базе `mercury-2` извлекает дату, время, длительность, заголовок, описание и при необходимости RRULE для регулярных событий, после чего создаёт запись в Google Calendar и отправляет подтверждение в Telegram.

В ветке идей отдельный AI-агент на DeepSeek преобразует свободный текст в JSON по схеме таблицы `public.ideas`, затем запись сохраняется в Supabase. После успешного сохранения воркфлоу отправляет карточку идеи в Telegram и логирует результат через Писца.

## Архитектура

```text
Telegram Trigger
  -> Проверка ID
     |- false -> Отказ - чужой ID
     '- true  -> Есть текст?
                 |- false -> TG Нет текста
                 '- true  -> Классификатор
                             |- calendar -> Ожидание Календарь
                             |             -> AI Agent Календарь
                             |             -> Create an event in Google Calendar
                             |             -> Форматировать ответ
                             |             -> TG Ответ Календарь
                             '- idea     -> Ожидание Идея
                                           -> AI Agent
                                           -> Parse JSON
                                           -> Supabase Insert Idea
                                           -> TG Успех Идея / TG Ошибка
                                           -> Set LOG Идея
                                           -> LOG через Писец
```

## Логика ИИ

Воркфлоу использует два разных AI-агента под разные задачи.

Календарный агент получает исходный текст, текущую дату и строгие правила: не задавать вопросов, не использовать прошлые годы, выставлять разумное время по умолчанию, передавать короткий заголовок, полный исходный текст в `description` и корректный `RRULE` для повторяющихся событий.

Агент идей работает как строгий структурный парсер. Он возвращает только JSON по заранее заданной схеме Supabase: `title`, `description`, `category`, `status`, `priority`, `tags`, `source`, `notes`. Если модель вернёт невалидный JSON, `Parse JSON` создаёт безопасный fallback-объект, чтобы запись всё равно не потерялась.

## Особенности реализации

▪ **Классификатор без LLM** — разделение на календарь и идеи выполняется быстрым JS-правилом по датам, времени и слову «идея».
▪ **Одна точка входа** — пользователь может писать в одном Telegram-чате и не думать о формате запроса.
▪ **Строгий whitelist по chat ID** — до основной логики доходят только сообщения из разрешённого чата.
▪ **Fail-safe для JSON** — даже при неидеальном ответе модели ветка идей не падает, а формирует запасной объект.
▪ **Асинхронный лог** — Писец вызывается без ожидания завершения, поэтому ответ пользователю не тормозится логированием.

## Необходимые credentials

| Credential | Назначение | Нода |
|------------|-----------|------|
| Telegram Bot API | Приём сообщений и отправка всех ответов | Telegram Trigger, все Telegram-ноды |
| OpenAI API | Языковая модель `mercury-2` для календарной ветки | OpenAI Chat Model |
